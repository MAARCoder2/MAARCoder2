## 🚀 Featured Projects

### **AI Madrasa Tutor** — Smart Learning for Islamic Studies
*An AI-powered educational system for Class 6 Madrasa students*

A secure multi-agent tutor built with **Google ADK** that provides:
- 📚 Textbook-grounded Q&A powered by RAG (Retrieval-Augmented Generation)
- 📝 Intelligent quiz generation and grading
- 📊 Real-time progress tracking and analytics
- 👨‍👩‍👧 Weekly parent progress reports
- 🕌 Quran and Hadith reference support
- 🔒 Security guardrails (content filtering, prompt injection protection)

**Tech Stack:** Python, Google ADK, LangChain, ChromaDB, OpenAI API

**Key Features:**
- Multi-language support (Bengali, English)
- Fallback to deterministic responses when LLM unavailable
- MCP (Model Context Protocol) integration
- Specialized agents: KnowledgeRetrieval, Quiz, Progress, ParentReport, QuranHadith

📂 **Repo:** [`madrasah-tutor`](https://github.com/MAARCoder2/madrasah-tutor)

### **Privacy Guard** — WhatsApp Privacy Protection
*A browser extension that blurs sensitive information on WhatsApp Web*

A lightweight, privacy-first tool that lets you blur messages, media, and contact names while taking screenshots or sharing your screen.

- ✅ 100% client-side processing (zero data collection)
- 🎯 Selective blur, blackout, and hover-to-reveal modes
- ⚡ Minimal performance impact

📂 **Repo:** [`privacy-guard`](https://github.com/MAARCoder2/privacy-guard)
